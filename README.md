# Prasad Web Studio Portfolio

A simple static portfolio website for selling one-page websites to local businesses.

## Files

- `index.html` - website content
- `styles.css` - website design
- `vercel.json` - Vercel settings

## Before publishing

Update these placeholders in `index.html`:

- WhatsApp number: `910000000000`
- Email: `yourname@example.com`
- Brand name: `Local Web Studio`

## Hosting on Vercel

1. Upload these files to a GitHub repository.
2. Go to Vercel and choose **Add New Project**.
3. Import the GitHub repository.
4. Keep the default settings and click **Deploy**.
